## Highlights

종횡비가 다른 Before·After 사진을 합성할 때의 분할이 개선되었습니다. 한쪽 사진이 가로, 다른 쪽이 세로처럼 비율이 다를 때 한 칸이 더 크게 차지하던 문제를 고쳐, 좌우·상하 합성 모두 두 칸을 정확히 50:50 으로 나누고 각 사진을 중앙 크롭으로 꽉 채웁니다. 또한 AFTER 촬영 화면의 BEFORE 스트립 카드에 각 사진을 가로로 눕혀 찍었는지 세로로 찍었는지 알려주는 방향 아이콘이 추가되었습니다.

---

## Added

- AFTER 촬영 스트립의 각 BEFORE 미리보기 카드 우상단에 촬영 방향(가로/세로) 아이콘 표시. 원본 EXIF orientation 기준이라 1:1 비율 사진도 정확히 구분 (`strip`)

## Changed

None

## Fixed

- 종횡비가 다른 Before·After 사진 합성 시 두 칸이 50:50 으로 나뉘지 않고 한쪽이 더 크게 차지하던 문제 수정. 두 칸을 동일 슬롯으로 통일하고 각 사진을 중앙 크롭(aspect-fill)으로 채워, 좌우 합성은 너비, 상하 합성은 높이가 정확히 절반씩 분할됨 (`composite`)

None

## Internal

- 익스포트 저장 서비스의 `PhotoLibraryExport` 의존성을 `PhotoLibraryExporting` 프로토콜로 추상화. 저장 단위 테스트가 실제 PHPhotoLibrary 권한 요청 없이 Stub 을 주입하도록 격리(테스트 hang 해결). 프로덕션 동작 변경 없음 (`export`)
- README 주요 기능 섹션 개편 및 프로젝트 배너 이미지 추가 (`readme`)
