## Highlights

구독 상태 처리의 정확성을 높인 릴리즈입니다. 애플 결제가 실패해 청구 재시도·유예 상태에 있는 구독은 이제 결제 기간이 끝나는 시점에 Pro가 정상적으로 해제됩니다 (이전에는 최대 60일까지 Pro가 유지됨). 첫 실행 Paywall에는 네이티브 닫기(X) 버튼을 추가해 진입 후 이탈 동선을 명확히 했습니다. 내부적으로는 더 이상 제공하지 않는 광고 제거(adFree) 전용 프로모션 차원을 제거해 멤버십 로직을 Pro 기준으로 단순화했습니다.

---

## Added

- 첫 실행 Paywall에 네이티브 닫기(X) 버튼 추가. 하단 "무료로 사용" 텍스트 진입로는 그대로 유지 (`paywall`)

## Changed

None

## Fixed

- 결제 실패로 청구 재시도(Billing Retry)·유예(Grace Period) 상태가 된 구독을 Pro 활성으로 더 이상 취급하지 않음. 결제가 성공하지 않으면 결제 기간 만료 시점에 Pro가 정상 해제됨. 구독·프로모션이 모두 활성인 경우의 동작에는 영향 없음 (`subscription`)

## Removed

None — 사용자 가시 기능 제거 없음 (adFree 전용 프로모션은 외부에 제공하지 않던 비공개 레거시 차원이며, 제거 내역은 Internal 참조)

## Internal

- adFree 엔티틀먼트 차원 제거 및 Pro 기준 일원화. 광고 제거는 Pro의 결과로만 결정되도록 정리하고, 멤버십·프로모션 계층 표면을 축소 (뷰 계층의 광고 숨김 플래그는 동작 유지). 프로모션 응답의 `adFree` 필드는 무시되어 구버전 앱과의 응답 호환성 영향 없음 (`promotion`)
- 미사용 `Sample.xcconfig` 제거 (`config`)
