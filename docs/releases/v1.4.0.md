## Highlights

기기 갤러리의 Before/After를 PairShot 페어로 등록할 수 있도록 기능 추가.

홈 필터 영역 리퀴드 글래스 적용 및 가시성 개선.

---

## Added

- 갤러리에서 페어 추가: 홈 툴바 `+` 버튼과 앨범 상세 `⋯` 메뉴에서 갤러리 사진으로 페어 등록. 카드 쌍 단위 가로 페이징 시트로 여러 쌍 연속 추가, 무료 일일 생성 한도는 촬영과 동일 적용, 앨범에서 추가 시 해당 앨범 자동 귀속. 생성 시각·GPS는 사진의 실제 촬영 메타데이터 사용 (`pair`)
- 홈 필터 영역 투명화 및 글래스 컨트롤: 전체/앨범 토글과 정렬 버튼이 불투명 블록 대신 글래스 컨트롤로 콘텐츠 위에 떠 있고, 스크롤 시 콘텐츠가 아래로 지나감. 토글 선택 시 하이라이트 슬라이드 애니메이션 (`home`)

## Changed

- 홈 상단 로고 좌측 정렬 (iOS 26 글래스 캡슐 미적용 처리) (`home`)
