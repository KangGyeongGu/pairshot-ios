## Highlights

- **개인정보처리방침 · 이용약관 · 마케팅 웹사이트 도메인을 `pairshot.nomadlabs.kr` 로 이전**: paywall 과 설정 화면에서 열리는 정책 페이지, 그리고 README 상의 웹사이트 링크가 모두 새 도메인으로 전환. 앱 사용자는 설정 → 개인정보처리방침/이용약관 진입 시 새 도메인의 페이지를 보게 됨. 쿠폰 등록 흐름의 서버 호스트 (`pairshot.kangkyeonggu.com` → `pairshot.nomadlabs.kr`) 도 함께 이전되어 프로모션·구독 동기화 API 가 새 호스트로 호출.
- **정책/웹 베이스 URL 의 하드코딩 제거**: 기존에는 `PaywallURLs.swift` 에 호스트 문자열이 박혀 있어 도메인 이전마다 코드와 테스트를 함께 손봐야 했음. 이번 릴리즈에서 쿠폰 API 와 동일한 xcconfig → Info.plist → Bundle 주입 패턴 (`WEB_BASE_HOST` → `WebBaseUrl`) 으로 통일해 다음 도메인 이전 시 xcconfig 두 줄 + README 한 줄만 수정하면 되도록 단일 출처화.

## Changed

- paywall 과 설정 화면의 개인정보처리방침 · 이용약관 페이지가 `pairshot.nomadlabs.kr` 도메인으로 열림. 한국어 로케일은 `/privacy` · `/terms`, 그 외 로케일은 `/privacy/en` · `/terms/en` 으로 분기 (기존 로케일 분기 동작 유지). (`host`)
- 쿠폰 등록 흐름의 `SFSafariViewController` 가 새 호스트의 `/redeem` 페이지를 열고, 프로모션 동기화 API (`/api/v1/pairshot/promotion`) 호출도 새 호스트로 전환. 기존 path 규약은 그대로 유지되어 사용자 체감 흐름은 도메인 표시만 변경. (`host`)
- README 의 웹사이트 마케팅 링크가 새 도메인으로 갱신. (`host`)
